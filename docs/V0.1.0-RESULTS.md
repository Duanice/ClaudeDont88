# v0.1.0 验证记录

本页保留首个构建的历史记录。安装 Claude 后的最新结果见 [build 2 验证记录](V0.1.0-BUILD2-RESULTS.md)。

验证日期：2026-10-20。环境：Apple silicon、macOS 26.5.2、Xcode 26.6、Swift 6.3.3。

**结论：软件原型构建与本地自动测试通过；真实网络拦截验收尚未完成。**

| 项目 | 结果 | 证据范围 |
|---|---|---|
| Swift Debug 构建 | PASS | 三个可执行目标及共享库编译链接成功 |
| Swift Release 构建 | PASS | 原生 App、测试客户端和系统扩展均生成 |
| 策略测试 | PASS | 12 个 XCTest 方法，包括多组地址、端口、协议和无效配置 |
| 系统代码身份测试 | PASS | 5 个 XCTest 方法，包括真实进程 audit token 与签名匹配 |
| TCP IPv4 echo | PASS | 测试客户端和本地接收端真实交换标记 |
| TCP IPv6 echo | PASS | 同上 |
| UDP IPv4 echo | PASS | 同上 |
| UDP IPv6 echo | PASS | 同上 |
| 非数值主机输入 | PASS | 客户端拒绝输入，避免默认 DNS 查询 |
| 端口无监听 | PASS | 客户端返回连接失败 |
| 预览包签名完整性 | PASS | `codesign --verify --deep --strict`；仅 ad-hoc 签名 |
| 系统扩展实际加载 | BLOCKED | 无所需网络扩展描述文件，账号为普通 Apple ID |
| Claude CLI 实机验收 | BLOCKED | 未安装 Claude CLI，系统扩展未加载 |
| Claude Desktop 实机验收 | BLOCKED | 未安装 Claude Desktop，系统扩展未加载 |
| 断代理/直连/切网/扩展崩溃的系统拦截 | NOT TESTED | 需要正确签名及隔离测试环境 |
| 上游 DIRECT 回退、子进程、强制结束任务 | NOT IMPLEMENTED | 属于后续工作 |

“TCP/UDP echo 通过”只说明测试工具工作正常，**不是**防泄漏验收。
本机未启用新过滤器，未改动既有代理和网络扩展配置。
GitHub CI 的具体平台与结果以仓库 Actions 对应提交的运行记录为准。

## 复现

```sh
swift test
python3 scripts/build_app.py
python3 scripts/probe_baseline.py build/ClaudeDont88.app/Contents/Helpers/guard-probe
codesign --verify --deep --strict build/ClaudeDont88.app
```

需要继续执行的实机步骤列于 [VALIDATION.md](VALIDATION.md)。在这些条件满足并验证之前，v0.1.0 只能作为预发布原型。
