# v0.3.0 验证结果

2026-10-20；Apple silicon，macOS 26.5.2，Xcode 26.6，Swift 6.3.3。

**独立任务守护与已登记后代的局部清理验证通过；真实 Claude 桌面联网启动和系统防泄漏未通过。** 所有时延都是一次本机测量，不是性能保证或泄漏上界。

## 自动验证

- 38 项 Swift 测试通过：原有 33 项、审计身份/代次拒绝/精确接管/路径别名 4 项，以及启动确认前不执行 1 项。
- 发布构建包含 App、探针、监督进程、任务守护、过滤器五个可执行目标；完整包通过 `codesign --verify --deep --strict`。
- 运行时脚本覆盖 18 项检查（包含已安装 mihomo v1.19.29 的回环测试），不访问 Anthropic：

| 故障或场景 | 结果 |
|---|---|
| 伪造 IPC 保护字段 | 真实 CLI/桌面启动仍拒绝 |
| 手动停止、控制 EOF、无效消息、状态管道中断 | 所属组结束 |
| 监督进程 SIGKILL | 所属任务组约 0.01 s 后停止 |
| 监督进程 SIGSTOP，模拟卡死 | worker 心跳超时，约 3.22 s 后停止任务组 |
| UI 停止发送心跳但保留管道 | 监督进程约 4.98 s 后结束任务组 |
| worker SIGKILL | 监督进程约 0.01 s 后清理所属任务组 |
| worker SIGSTOP 后手动停止 | 回执超时后约 1.05 s 完成所属组强退 |
| 没有启动确认 | 目标始终挂起；心跳超时清理，未创建目标应写出的文件 |
| 已观察子进程脱组 | 终止成功，另一会话仍运行 |
| 双重 fork 立即守护化 | 精确签名/会话参数规则接管并终止，另一会话仍运行 |
| 专用代理崩溃 | 任务组结束，私有配置删除 |
| 监督进程被强杀且代理运行中 | 代理和任务停止，私有代理目录删除 |
| 出口检查 worker 被强杀 | 清理状态标为未知，代理和任务停止，拒绝创建新会话 |
| 真实 mihomo + 回环 HTTP 上游 | 经上游请求成功，本地代理拒绝无认证请求 |
| 上游断开 | 经专用代理失败，直接接收端无请求；直接正向对照仍可达 |

CI 不安装第三方内核，也不启动真实 Claude。对应提交的 CI 状态在 GitHub Actions 中记录。

## 本地界面

已直接操作发布构建的 v0.3.0 窗口：

- 启动不联网演练后，任务持续运行超过 8 秒，显示“监督连接正常”和实际任务 PID。
- 点击“强制结束”后，worker、shell 和 sleep 均退出；监督连接保持正常。
- 再次启动演练并退出 App，App、监督进程和该次任务组均退出。

## 真实 Claude

已用官方 Claude 2.42304.2 临时实例复测，增加崩溃报告进程接管规则和标准错误采集。

- 用户原有 9 个 Claude 进程保留；已观察到的测试实例进程在结束后无残留。
- 确认 Electron Helper 报出沙箱初始化权限错误，随后 GPU／网络服务退出，主进程状态为 5。
- 测试代理请求为 0；实机脚本以 `2` 表示启动验收不完整。
- 未登录临时实例，未提交真实 Code 任务。没有完成实际代理路径、DNS、UDP、IPv6 或虚拟机覆盖的实机证明。

完整系统过滤仍不能加载到当前环境，故没有将 echo/回环测试或轮询清理计为真实防泄漏验收。
