- 路径：`/Applications/Claude.app`。

- 桌面包 `codesign --verify --deep --strict` 通过；扫描器另外验证每个原生程序的签名、所有架构及发布者要求。
- 扫描得到 **16 个原生可执行文件、13 个不同签名身份**。四个 Electron Helper 共享同一个指定签名要求，因此去重后只占一个身份。
